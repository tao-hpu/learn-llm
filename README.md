# learn-llm

[learn-llm.fim.ai](https://learn-llm.fim.ai) 的源码：「从零手写大语言模型」课程的交互可视化，21 章，从 bigram 写到 GPT-2 124M，再到后训练、现代架构、推理效率与 RLVR。

配套的 Python 代码与 notebooks 在 [tao-hpu/llm-from-scratch](https://github.com/tao-hpu/llm-from-scratch)。

## 本地运行

```
pnpm install
pnpm dev
pnpm build
```

技术栈：Vite、React、TypeScript、react-router。交互用手写 SVG、canvas 与 DOM，不依赖图表库。
